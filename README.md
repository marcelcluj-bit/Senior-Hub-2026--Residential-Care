# 🏛️ Senior Hub 2026 - Smart Residential Infrastructure for Seniors ($SENIOR)

> **nZEB Standard & IoT-Driven Assisted Living Framework (PNRR / Public-Private Partnership Compatible)**

## 📌 Overview
**Senior Hub 2026** is an open-source model blueprint designed for municipal and private deployment of smart residential senior care infrastructure. The framework covers a 650 sqm nearly Zero-Energy Building (nZEB) accommodating 18 residents, fully integrated with IoT health monitoring, predictive care analytics, and **Gemini AI Core** decision support.

---

## 🏗️ Repository Architecture
* `contracts/` - Smart contracts for escrow management and voluntary pension contribution tracking (`SeniorHubEscrow.sol`).
* `ai-core/` - Python engine (`gemini_health_iot_monitor.py`) for IoT telemetry, fall detection alerts, and nZEB energy optimization.
* `financials/` - JSON budget model outlining the €1,200,000 capital expenditure and operational cash flow.
